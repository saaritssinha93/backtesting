# G-3 09:20 LONG historical backtest

Deployment update: the configuration was subsequently promoted to the shared
G3 production V3 daily/PAPER/LIVE rule book. See
[the production migration record](G3_0920_LONG_PRODUCTION_2026-10-13.md).
The separate scheduled daily sidecar described below has been removed; the
saved historical comparison and its retrospective-data limitations remain.

Dashboard Flow's default G-3 backtest now uses the sealed backtest-only
`V13-V10-G-3-BT-0920-LONG-T300-V1` overlay. It retains the 49-session G-3 V2
baseline, including the 09:50 LONG setup, and adds the selected 09:20 LONG
orders with a 3.00% target. No 09:20 SHORT orders are selected. The existing
1.25% initial stop, 1.00% stop after 120 minutes, 15:15 square-off, five-basis-
point round-trip backtest cost, and portfolio sizing are unchanged.

The completed July 29–October 12, 2026 comparison has 112 baseline executions,
80 wins and ₹286,682.16 net. The eight additional 09:20 LONG executions have
six wins and ₹68,339.73 net. Together they have 120 executions, 86 wins
(71.67%) and ₹355,021.88 net. The model uses ₹100,000 margin per trade with
five times exposure; these rupee results are not scaled to the live ₹10,000
margin plan. October 1 is absent from the sealed 49-session baseline and has
not been treated as a zero-trade day.

The 09:20 OI baseline was recovered retrospectively. Live availability at the
decision time remains unverified. The scheduled production daily replay and
LIVE/PAPER rule book still use their original G-3 production contract. The
weekday backtest task then runs a **separate 09:20 LONG daily sidecar** after
the normal daily result. Both 09:20 backtests have no execution authority.
The 49-session overlay is selected by default in Dashboard Flow's G-3
historical backtest view; the newest daily sidecar and original verified
production history are separately selectable in the run selector.
The 49-session historical overlay is fixed through October 12; later daily
sidecars do not silently extend or relabel that historical cohort.

For October 12, the daily replay has one existing G-3 win worth ₹4,600 net.
The 09:20 LONG sidecar adds one losing POLYCAB trade worth −₹725.74 net, so
the combined daily result is two trades, one win and ₹3,874.26 net. The
sidecar exposes this loss alongside the positive full-history result rather
than hiding it in the aggregate.

Reproduce the fixed historical result into a new directory:

```powershell
python -m research.g3_0920_long_current --no-publish --output-dir C:\TradingData\eqidv2\backtesting_result_v13_v10_g_3\backtests\runs\2026-10-12\NEW_0920_long_t300
```

Omit `--no-publish` only when intentionally replacing the dashboard's
`latest/current_0920_long_backtest.json` pointer with a fully verified run.
The runner checks the sealed baseline, dated stock universe, source hashes,
selected opening/OI inputs, minute execution paths, and baseline trade parity.

The weekday `bat/run_backtesting_result_v13_v10_g_3_1620.bat` calls
`python -m research.g3_0920_long_daily --date YYYY-MM-DD` only after the
production daily publisher finishes successfully. Missing or invalid opening
evidence prevents publication of a new sidecar, and the last verified sidecar
remains available for comparison.
