- Existing ticker5m files end July 31. They add zero previously unavailable closes beyond the core sources for selectable sessions.
- All 1,041 existing daily cash files are stale: 1,019 end May 15, 12 end April 17, 5 end April 9, and 5 end March 2. Existing stock cache directories are empty.
